# Introduction to Bayesian Multilevel Latent Time Series Models with the R-package `mlts`

Hi everyone!

Here, you find the workshop materials.

* The directory `live_session` contains scripts (and solutions) for the hands-on session exercises. You can directly work within the script or create them yourself!
